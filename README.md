# Къща за гости Фенер / Guest House Fener

https://a1xs.github.io/Fener-House/

Едностраничен сайт за Къща за гости Фенер в Поморие.

## Структура

- `index.html` - основна страница
- `css/styles.css` - стилове
- `js/script.js` - функционалност
- `images/` - снимки (header.jpg + 40+ галерийни снимки)

## Функции

- Превключване БГ/EN/RU
- Responsive дизайн
- Галерия с lightbox
- Клавиатурна навигация (←/→/Esc)

## Отваряне

Отворете `index.html` в браузър.
